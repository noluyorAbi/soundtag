# Promotion

Channel rules change. Every rule below was read from the channel itself, and the date is on it. Re-read anything older than a month before posting.

## The frame

Not "another Spotify code generator". There are hundreds, and the novelty is spent before the first post goes up. What is not spent:

> The geometry was the easy half. The time went into proving the printed object needs exactly one filament change, and into three things I believed that turned out to be false.

One sentence: **a song becomes an object, with the colour change already assigned, and every number in the README was measured.**

## Before any of it

| Step | Why it blocks the rest |
|---|---|
| `v0.1.0` on npm with a provenance badge | A broken `npx` line in a Show HN post cannot be taken back |
| One tag printed, photographed, scanned, result in VERIFY-LOG.md | Without a photo a maker post is weak, and the most honest line in the project is currently empty |

## Wave 1, launch day

Tuesday to Thursday, 17:00 to 19:00 Berlin for Hacker News.

| Channel | The rule that shapes the post |
|---|---|
| Show HN | Site in the URL field, everything else in the text. Lead with the parser and the two verification harnesses, not the keychain. Never ask for upvotes |
| r/SideProject | Title format `[Project] - [description]` |
| r/somethingimade | Photo first. A printed tag on a keyring is exactly this sub's format |
| X | Native video in the post, link in the first reply |
| Bluesky | Links are not penalised. The lever is custom feeds, and there are active 3D printing and laser feeds |
| Mastodon | Invisible without hashtags. This audience checks licences and trademarks, so MIT and "not affiliated" belong in the first two lines |
| LinkedIn | What I built and what was hard. Link in the first comment |

## Wave 2, the repository wave, days two to five

| Channel | Note |
|---|---|
| Hackaday tip line, `tips@hackaday.com` | The largest single press lever. Short human email, three measurable surprises, offer images. Not a press release |
| r/lasercutting, r/lasercutters, r/xtool, r/glowforge, r/Lightburn | The SVG export doubles the audience for almost no extra code. Post the cut and engrave split and the kerf note |
| r/prusa3d, r/BambuLab | Settings with reasons, one line each. Invites print profiles |
| r/opensource | Opens with MIT. The sub has its own rule against posts written by a language model |
| r/coolgithubprojects | Language in the title |
| `ad-si/awesome-3d-printing`, under `## Online Tools` | One entry per pull request, AP title case, `[Name](link) - Description.` |
| Console.dev, Web Tools Weekly, Frontend Focus, Changelog News | Three to five sentences, one non obvious property, the licence, the source link |
| Dev.to | Long lived. Tags `#3dprinting #lasercutting #typescript #opensource #showdev` |

## Wave 3, week two, gated on a printed photo

Printables, Thangs, Vercel community showcase, AlternativeTo, SaaSHub, Peerlist, DevHunt.

**One demo model, not a series.** Use a track whose rights are clear, say which in the description, and do not put the trademark in the model title. Uploading a library of tags for popular songs is the fastest route to a takedown, and the launch must not depend on these channels.

## Refused

- r/3Dprinting as a link post: software sharing is unwelcome there regardless of self promotion rules
- r/spotify and r/truespotify: support subs, and the least friendly possible room for the trademark question
- Any print and ship affiliate link: around someone else's trademark that is how a cease and desist arrives
- Product Hunt in summer: one slot, six month lock. It belongs in the first week of December, next to Spotify Wrapped

## Seasonality

A song keychain has two peaks and this project should use both.

- **Now**: indexing, listings and backlinks. Awesome list entries merged, npm published with provenance, the Dev.to article live. None of this needs a viral moment
- **Late November to 10 December**: gifting plus Spotify Wrapped, which lands around 3 December and pulls the whole category with it. Product Hunt goes here
- **20 January to 10 February**: song plaques and keychains are a Valentine's category. Small second wave: r/somethingimade, r/lasercutting, short video

## The question that arrives in every thread

"Can I sell these?" Write the answer once, paste the same three sentences every time, and never improvise it live:

> No, and the repository says so. Spotify's terms for Spotify Codes forbid using a code directly on products that are sold, because it implies an endorsement of the product. This exists so you can make one for yourself or for someone you like.

Second question: "does it scan when printed?" Answer with the row from VERIFY-LOG.md, or with "not measured yet, and here is the log".

## What gets counted

Three numbers a week, in a file, not a dashboard: GitHub stars, npm downloads, unique visitors. Target for the first 30 days, deliberately low so it stays honest: 150 stars, 300 downloads, and one photo of somebody else's printed tag in an issue. The third one matters most.
